Como uma página web é construída?

Uma página web pode combinar diferentes tecnologias. Cada uma contribui de uma forma para que o conteúdo seja organizado, compreensível e agradável de usar.

As três tecnologias principais

HTML: estrutura

HTML significa Hyper Text Markup Language. Ele utiliza elementos e tags para marcar títulos, parágrafos, imagens, links, listas e outras partes do conteúdo.

CSS: apresentação

CSS significa Cascading Style Sheets. Ele controla a apresentação visual, como cores, fontes, margens e a disposição dos elementos na página.

JavaScript: comportamento

JavaScript é uma linguagem de programação que pode responder às ações das pessoas, validar formulários e atualizar partes da página.

Um caminho para começar

  1. Entender a estrutura básica de um documento HTML.
  2. Praticar títulos, parágrafos, listas, imagens e links.
  3. Aprender os fundamentos de CSS.
  4. Estudar JavaScript e criar pequenos projetos.
